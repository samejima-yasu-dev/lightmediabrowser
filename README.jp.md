# LightMediaBrowser

**LightMediaBrowserは、大量のローカル動画を整理・閲覧するための、高速で軽量なローカルファーストアプリケーションです。**

<img width="2560" height="1543" alt="Screen" src="https://github.com/user-attachments/assets/880624bd-9cc3-43e8-8ed3-412a1a702df6" />

動画コレクションのスキャン、閲覧、検索、タグ付け、整理に特化しています。

**動画プレイヤーではありません。** 再生には、VLC、mpv、MPC-HC/BEなど、お好みの外部プレイヤーをご利用ください。

> **ステータス: 0.0.10-alpha**
>
> 初期アルファ版です。基本的なワークフローは利用できますが、今後機能や内部構造が変更される可能性があります。

---

## LightMediaBrowserを使う理由

動画ファイルが増えると、ファイルマネージャーだけでコレクションを探したり整理したりするのが難しくなることがあります。

LightMediaBrowserは、動画コレクションを管理するための軽量なローカルライブラリです。

* 複数のローカルフォルダーをスキャン
* サムネイル付きの動画一覧を表示
* 選択した動画を、最初のフレームを避けた大きめの3枚の場面サムネイルで確認
* コレクションを検索・絞り込み
* タグで動画を整理
* 動画のメタデータを確認
* お気に入りを登録し、再生回数を記録
* 好みの外部プレイヤーで動画を再生

動画プレイヤーを置き換えるのではなく、**動画コレクションの管理**に専念します。

---

## 主な機能

### 動画ライブラリ

* 複数のフォルダーを追加・管理
* フォルダーを再帰的にスキャンして動画ファイルを検出
* サムネイル付きの一覧で動画を閲覧
* 元の動画ファイルは変更しません

### 快適なブラウジング

* フォルダーの非同期スキャン
* サムネイルの非同期生成
* サムネイルキャッシュ
* 詳細ペインの追加サムネイルは選択中の動画だけ生成し、次回以降はキャッシュを再利用
* データベースを使ったライブラリ管理
* 大規模なローカル動画コレクションを考慮した設計

### 検索と絞り込み

* ファイル名や保存済みの情報から動画を検索
* お気に入り、再生回数、タグなどで絞り込み
* ファイルサイズが同じ動画を候補として表示

同じファイルサイズであることは、動画の内容が同一であることを示すものではありません。

### タグと整理

* タグのカテゴリを作成
* 動画にタグやメモを追加
* お気に入りを登録

### 動画メタデータ

次のような情報を取得して表示します。

* 再生時間
* 解像度
* 映像・音声コーデック
* その他の取得可能なメディア情報

### 外部プレイヤー

LightMediaBrowserには、**動画プレイヤーを内蔵していません**。

動画を開くと、OSに関連付けられたプレイヤーで再生します。使い慣れたプレイヤーをそのまま利用できます。

> **動画は整理する。再生は、いつものプレイヤーで。**

---

## ローカルファースト・非破壊

LightMediaBrowserは、ローカルにあるメディアコレクションを管理します。ライブラリ情報は元の動画ファイルとは別に、SQLiteデータベースへ保存します。

次の操作は行いません。

* 動画をクラウドサービスへアップロード
* オンラインアカウントの要求
* 元の動画ファイルを変更
* 動画の変換
* 既存の動画プレイヤーの置き換え

**あなたのメディアファイルは、あなたのものです。**

---

## データの保存場所

ライブラリ情報はSQLiteデータベースに、アプリケーション設定はQtの設定システムに保存します。

ツールバーの **Thumbnail Threads: Limited / Unlimited** で、サムネイル生成に使う並列スレッド数の上限を切り替えられます。既定ではCPU負荷を抑える上限が有効です。ボタンの表示で現在の設定を確認でき、変更は次回起動時にも引き継がれます。

Linuxでの既定の保存場所は次のとおりです。

```text
~/.local/share/LightMediaBrowser/database.sqlite
~/.config/LightMediaBrowser/LightMediaBrowser.conf
```

### 削除・移動された動画について

利用可能な登録フォルダーを完全にスキャンできた場合に限り、そのフォルダー内で見つからなかった動画のデータとサムネイルを削除します。スキャンが不完全な場合やフォルダーにアクセスできない場合は、誤削除を防ぐためデータを保持します。外付けドライブが一時的に切断されている場合も、再接続後に利用できるよう登録情報を残します。

## 開発状況

**現在のバージョン: 0.0.10-alpha**

LightMediaBrowserは現在、初期開発段階にあります。

動画管理の基本的な流れは、ひととおり実装されています。

```text
フォルダーを追加
    ↓
動画を検出
    ↓
サムネイルを生成
    ↓
ライブラリを閲覧
    ↓
検索・絞り込み
    ↓
タグ付け・整理
    ↓
外部プレイヤーで再生
```

0.0.xシリーズは、基本設計と操作の流れを検証するための開発版です。次のような変更が入る可能性があります。

* 不具合や未実装の機能
* UIの変更
* データベーススキーマ、API、内部構造の変更

フィードバックや不具合の報告を歓迎します。

## LightMediaBrowserが目指さないもの

LightMediaBrowserは、あらゆるメディア機能を一つにまとめることを目指していません。

次の用途を目的としたアプリケーションではありません。

* 動画プレイヤー
* 動画編集・変換ソフト
* メディアストリーミングサーバー
* クラウドメディアサービス

目的はシンプルです。**ローカルの動画コレクションをすばやく管理・閲覧すること。**

## 動作環境

ビルドと実行には、次の環境が必要です。

* CMake 3.21以降
* GCCやClangなどのC++20対応コンパイラ
* Qt 6開発パッケージ
* SQLite 3開発パッケージ
* 実行時に利用できる `ffmpeg` と `ffprobe`

### Ubuntu / Debian

```bash
sudo apt update

sudo apt install \
  build-essential \
  cmake \
  qt6-base-dev \
  libsqlite3-dev \
  ffmpeg
```

## ビルドと実行

リポジトリをクローンし、プロジェクトのルートで以下を実行します。

```bash
git clone https://github.com/samejima-yasu-dev/lightmediabrowser.git
cd lightmediabrowser
```

```bash
cmake -S . -B build
```

```bash
cmake --build build -j$(nproc)
```

```bash
./build/lightmediabrowser
```

サムネイル生成と動画情報の取得には、`ffmpeg` と `ffprobe` が必要です。

## 設計方針

LightMediaBrowserは、次の方針を大切にしています。

### ローカルファースト

メディアライブラリはローカル環境に保存します。

### 非破壊

元のメディアファイルを変更しません。

### 快適なブラウジング

スキャンとサムネイル生成は非同期で行います。生成したサムネイルをキャッシュし、次回以降の表示に再利用します。

### 軽量さ

あらゆるメディア機能を詰め込まず、動画管理に必要な機能に集中します。

### 好みのプレイヤーを使う

動画の再生は外部プレイヤーに任せるため、使い慣れたプレイヤーや設定をそのまま利用できます。
